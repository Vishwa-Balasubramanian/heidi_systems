# Architecture

`main.py` coordinates import → normalize → deduplicate → enrich → validate → score → export.

- `src/identity.py`: JSON/CSV/XLSX adapters and conservative identity matching. Original rows stay intact. Legal suffixes remain part of identity; common-domain matches alone never merge entities.
- `src/models.py`: typed companies, contacts and field evidence. Unknown facts are null. Portfolio counts cannot be negative.
- `src/sources.py`: public HTTP(S), robots policy, timeouts, per-host spacing, limited redirects and saved HTML/text snapshots. Snapshot mode only reads disk.
- `src/extraction.py`: versioned positive phrase matching with contextual quotes. Counts require an explicit self-description. Missing phrases are not negative facts.
- `src/scoring.py`: pure evidence-gated qualification, independent contact readiness, completeness and upper bound.
- `src/export.py`: six-tab openpyxl workbook, literal text cells, source hyperlinks, frozen headers and filters.

The baseline Python export remains the detailed six-tab workbook. The final Berlin AI presentation is regenerated by `tools/refresh_simple_workbook.py`: allowlisted website/contact data feeds the Artifact Tool builder, native hyperlinks are added to the XLSX package, and readback checks confirm every lead. Its three tabs are Priority Leads, All Companies, and Sources & Methodology. `tools/finalize_berlin_ai.py` runs this presentation step after offline evidence validation. The Vercel website serves exported data and Excel without runtime model calls.

Concurrency uses a bounded thread pool, not agents. Failures are isolated to a row/page and written to manifests. A shared host scheduler spaces requests across company fetchers. Raw HTML is content-addressed; URL pointers select the latest captured page for offline replay. Archive the entire cache and config to freeze a particular dataset. Raw data and contact-bearing results are gitignored.

The imported Google Sheet is a manually captured connector snapshot. The repository can independently replay that saved input or import a fresh CSV/XLSX export. Google write synchronization and direct new-directory parsing are not implemented. Source selection currently exposes the import adapter only.
